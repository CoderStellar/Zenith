Zenith

A West Coast Climate Assessment Tool for Alaska · California · Hawaii · Oregon · Washington

What is changing in the Pacific states, and how sure are we?

What it is

Measured trends in temperature, rain, smoke, water storage and soil moisture for the US West Coast: Alaska, California, Hawaii, Oregon and Washington.

Why it exists

Choosing a region and the variables to look at is hard. Then you need to know whether they are really changing, and whether one moves with another. NASA’s raw data does not explain itself. This tool tests each trend, finds which variables move together, and explains the result in plain language using only the computed numbers. It never claims cause.

Its link-finder was run against 25 published results and matched 24.

Who it is for

Anyone who needs to see what is changing without being a climate scientist: students and teachers, journalists, local planners. Researchers will find the tests, the correlation engine and the sources in About, and can try any place on Earth in “Try it out yourself”.

How it works

Data: NASA satellite and climate-model records, mostly 1980–2024 (rain from 2001, water storage from 2003), averaged over each state’s outline. Generated .

Test: we fit a straight line and ask whether the change is bigger than normal year-to-year swings. “Clear rise” or “clear fall” means it is unlikely to be chance (95% confidence). “No clear trend yet” (faded colours) means the change so far is within normal swings, so it could still be noise.       Methodology

      1. Regions. US Census 2024 state outlines. Each grid cell counts by the share of it inside the state, weighted by cos(latitude), like NASA Giovanni's shape masks. Alaska's outline is cut at 180° (the far-western Aleutians are left out).
      2. Data. Monthly NASA products, fetched through NASA Earthdata (Harmony subsetting and Giovanni's averaging service): air temperature (MERRA-2 M2TMNXSLV, 1980–2024), precipitation (GPM IMERG V07, 2001–2024), aerosol optical depth (MODIS Aqua MYD08_M3, summers 2003–2024), total water storage (GRACE/GRACE-FO JPL mascons, 2003–2024), soil moisture (GLDAS Noah 2.1, 2003–2024).
      3. Trend. A straight-line trend fitted together with the seasonal cycle on the real monthly calendar (gaps such as GRACE's 2017–18 gap stay gaps). For smoke, the trend of each summer's June–August average.
      4. Significance. Neighbouring months are not independent, so the test uses an effective number of months from the lag-1 autocorrelation (the adjustment IPCC AR6 uses, Santer et al. 2008). The 95% range and p-value come from that test.
      5. Verdict. “Clear rise/fall” needs p < 0.05 and a robust Theil–Sen slope with the same correction pointing the same way. Otherwise “no clear trend yet”: the change so far is within normal year-to-year swings, so it could still be noise. That is not the same as “no trend”; a longer record may settle it.
      6. Explanations. The “What this means” text is written by an AI model from a fact sheet of the computed numbers. A checker rejects any number not in the results, causal claims (“caused by”, “proves”) and filler words; if a reply fails twice, a plain template sentence is shown instead.
      7. Units. Temperature in °C per decade; precipitation and soil moisture as % of the state's average per decade; smoke in aerosol optical depth per decade; water storage in mm of water per year (and km³/yr for the whole state).
      8. Pipeline. scripts/build_tool_data.py in the earthpull project downloads, clips, averages and tests everything, then writes data.js. The site itself is static and does no processing.

      Correlation engine

      "What moves together here?" in the Try tab. No AI: fixed statistics and a fixed physics table. The strongest wording it uses is "consistent with A influencing B", never "causes".

      1. Clean-up. Each calendar month's normal value is removed (seasons), then each variable's trend is removed with the same fit as the trend test, so two variables that merely both drift are not called linked.
      2. Move together? Lagged correlation (0–3 months, either direction), with an effective sample size from each series' lag-1 autocorrelation (Bretherton et al. 1999), Benjamini–Hochberg false-discovery correction across all pairs and delays, and a surrogate test (phase-randomised series that keep each variable's own rhythm).
      3. Not explained by the rest? Partial correlation, controlling for every other variable chosen.
      4. Timing. Granger causality test in both directions (does A's past help predict B?), used only to flag one-way timing.
      5. Physics. A fixed table of 26 known mechanisms (for example rain → soil moisture, warmer air → drier soil, snowfall → snow depth). Only listed pairs, with the expected sign and delay, reach the top verdict. "Same" pairs (two measures of one thing) should agree; "shared" pairs (common source) are never called a cause.
      6. Is a trend explained by another variable? The variable is refitted with the other one added (same memory-adjusted errors). If the other one has no significant effect of its own, or is itself just a steady trend with no known mechanism, the engine says the two "cannot be separated".

      Guardrails

      • Trends, not causes. The tool reports what changed and how sure the statistics are. It does not say why.
      • Not a forecast. Past trends do not predict the future, and nothing here is emergency, insurance, planning or legal advice.
      • Resolution limits. State averages hide large local differences. GRACE's footprint is about 300 km, so Hawaii's water-storage trend is not reliable, and state totals leak across borders (shown as a range).
      • Relative charts. The change profile ranks these five states against each other only.
      • Tested against published studies. All 25 checks against published studies were run; 24 matched the published result (96%), and the one miss is explained by the dataset. The dataset limitations they revealed are listed below.
      • Attribution. Built with NASA open data. Not affiliated with or endorsed by NASA.
      • Privacy and accessibility. No accounts, tracking or personal data. Keyboard-navigable tabs, labelled controls, and text versions (ranking list, detail table, profile list) of every chart.

        Run it

        The Homepage and Map tabs work as a static site. "Try it out yourself" needs the tool server, which fetches NASA data on demand (a free NASA Earthdata login is required on the server):

        .venv/bin/uvicorn earthpull.api:app --port 8000 then open http://localhost:8000

        Variables with a global file on the server (air temperature, aerosol, MODIS AOD, GRACE) answer in seconds anywhere on Earth; others take from seconds (Giovanni averaging) to a few minutes the first time, then are cached.
